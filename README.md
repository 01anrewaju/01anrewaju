# Hi, I'm Olanrewaju Alaba 👋

**Data Scientist | Geospatial Machine Learning | Data Engineering**

I build machine learning models and data pipelines that turn large geospatial and environmental datasets into decisions. Right now I'm a Data Scientist on the analytics team at **GeoTechEnvision Africa**, where I've worked since July 2025.

---

## 🌍 What I Work On

- **Geospatial ML:** I design, build and deploy predictive and statistical models on large-scale geospatial and environmental data.
- **ETL pipelines:** I automate pipelines that ingest, clean and process structured and unstructured geographic data in PostgreSQL/PostGIS.
- **Spatial analytics:** I run trend evaluation, variance modelling and predictive spatial analysis for infrastructure and environmental projects.
- **Dashboards and visualization:** I build interactive Power BI and Streamlit apps that put model outputs in front of teams and stakeholders.
- **MLOps:** I work with software and GIS engineers to check model accuracy, reduce data drift and speed up code running on cloud infrastructure.
- **Documentation:** I write up methods, workflows, data schemas and API integrations so the work can be audited and reused.
